# 0006 多选只留 Enter 切换

## 决定

多选只认 `Enter` 与数字键 `1–9` 切换勾选。`Space` 不再切换，也不再出现在提示里（提示写 `enter toggle`）。

## 为什么

- `Enter` 与数字键已经覆盖「切换一项」，`Space` 是第三条路，提示还要多写 `/space`。
- 空格在列表态语义最弱：用户常在自由输入里按空格，列表态却默默改勾选。
- 少一个键位，底部提示更短，屏幕留给内容。

## 代价

- 以前用 `Space` 的用户要改按 `Enter`；README 与键提示都已写明。
- [0005](0005-multi-confirm-row.md) 里「Enter / Space / 数字键都切换」的描述以本文件为准。
