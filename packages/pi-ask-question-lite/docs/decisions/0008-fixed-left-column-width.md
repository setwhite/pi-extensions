# 0008 左栏宽度按整题内容定死

> 宽度公式由 [0012](0012-content-driven-column-width.md) 取代：上限不再是 `min(floor(width × 0.42), 54)`，两栏按各自内容分。

## 决定

- 并排时左栏宽 = `min(cap, max(12, 当前题全部左侧内容的最大宽度))`，`cap = min(floor(width × 0.42), 54, width - 3 - 12)`。
- "全部左侧内容"指 Tab 栏、题干、**所有**选项（含已滚出窗口的）与 detail、`+ Custom…` / `→ Confirm`。正在编辑的输入行不参与测量。
- 左栏每一行先按该宽度截断，再补空格对齐竖线。

## 为什么

[0007](0007-preview-column-top-aligned.md) 按裁剪后可见的行量宽度：选项窗口一滚动，最长的那行被裁掉，竖线左移，整块预览跟着横跳。宽度改成按题算一次，滚动与换高亮都不再动它。

## 代价

- Tab 栏很长时左栏直接顶到 cap，右栏变窄；宁可牺牲列宽也不再抖。
- 编辑 note / custom 时按固定字面量兜底，输入框内容不进测量：打字不会让竖线动，但输入框宽度也不再由内容撑开。
- 同一题内宽度固定，换题仍会变；跨题对齐不在承诺里。
