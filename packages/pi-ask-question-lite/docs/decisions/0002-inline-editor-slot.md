# 0002 挂编辑器槽位，不用 overlay

## 决定

`ctx.ui.custom(factory)` 走非 overlay 形态，组件占编辑器槽位。

## 为什么

- 问答期间要能看上方对话。overlay 盖在对话区上，捕获焦点后翻页归属还得自己接。编辑器槽位本就在对话区下方，宿主关闭组件时自动还原编辑框文本。
- 宿主给对话框的正式位置就是这里；非 overlay 路径不注册 abort 监听，正好由组件自己收 Esc（见 [0001](0001-esc-aborts-turn.md)）。

## 代价

- 组件高度直接吃掉对话区，必须自己按 `ui.maxHeightRatio` 裁剪（spec「界面」一节）。
- 编辑器原有的键在问答期间不生效，包括 `ctrl+g` 外置编辑器。首版不做外置编辑器，不冲突。
- 非 overlay 形态没有 `visible()` 回调，窄屏只能靠渲染时的宽度决定并排还是堆叠。
