# screenshot

`browser-extension/background/page/screenshot.js` 与 `src/fs/`

## 取舍

- 扩展只截图；落盘、命名与修剪在宿主 `src/fs/`。路径与保留期属于宿主配置，扩展不碰文件系统。
- 分块按页高均分，不按视口高硬切：页面刚过 4 倍视口时硬切会剩几像素的末段。
- 分块截图的每张图各占一个保留位，写之前先腾位；保留位装不下这一批就报错，不静默丢页面内容。腾位腾得紧时，旧的多段截图会被拆掉一部分。
- 超时上限管整次整页截屏，不按每段各算一次。
- 修剪只认 `.png` 与 `.jpeg`，目录里别的文件既不计数也不删除。
