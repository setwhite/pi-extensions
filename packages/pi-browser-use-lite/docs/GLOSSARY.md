# 术语 · pi-browser-use-lite

一个概念只用一个词。出现同义词时改成本表的词。

| 词 | 含义 |
|---|---|
| 桥 | `127.0.0.1` 上的本地 HTTP 服务。Pi 扩展与 Chrome 扩展在它上面交换命令与结果 |
| 命令 | Pi 侧发出的一次请求。含 `action` 与 `params` |
| 动作 | 命令里的 `action` 取值，例如 `page.click` |
| 结果 | Chrome 扩展回传的应答。含 `ok`、`result` 或 `error` |
| 工具 | 暴露给模型的 `chrome_*` 入口。默认 5 个，可逐个关闭或改名 |
| 规则 | 随工具一起发给模型的条目，走 `promptGuidelines`。关掉工具时一起消失 |
| guidance | 配置里覆盖工具说明、工具清单行与规则的字段 |
| 分派器 | 一个工具按 `action` 分派到多个行为的写法 |
| 自动化 target | 本 Pi 会话独占的窗口与标签页。模型不带 `tab` 参数时作用于它 |
| 会话窗口 | Pi 打开的标签页所在的浏览器窗口。一个会话一个窗口 |
| ref | 快照返回的元素标识。页内稳定，跨页失效 |
| 快照 | 对页面的一次结构化读取。产出 ref、正文、表单与可点的动作 |
| 授权 | `/chrome authorize on` 后模型才能用工具。只在会话内有效，会话结束自动关 |
| 错误类别 | 错误结果里的 `class` 取值，例如 `locked`、`no_target`。每个类别配一句 `hint` |
