# T04 工具面冻结

- [x] 已完成（2026-11-07 审计 pass）

## 交付物

5 个工具的 TypeBox 定义、各自的默认 `promptGuidelines` 常量按 [SPEC-0001](../specs/0001-tool-surface.md) 写好。`prompt.guidelines` 的默认全局规则已由 T03 落在 `src/config/schema.ts`，本任务只消费。注册层按 `tools.*`、`guidance.*` 与 `prompt.guidelines` 裁剪工具面与规则。预算测试就位。

## 验收

- AC1：`pnpm --filter pi-browser-use-lite test tool-surface` 通过。
- AC2：默认配置下断言工具恰好 5 个，名字依次为 `chrome_act`、`chrome_see`、`chrome_tab`、`chrome_vision`、`chrome_cdp`。
- AC3：测试断言 `JSON.stringify(5 个定义)` 的字符数 ≤ 12000。
- AC4：`chrome_act` 的 `action` 枚举含 12 个值且不含 `tap`；`chrome_tab` 的 `action` 枚举等于 `["list","new","switch","close","group"]`；`chrome_see` 的 `mode` 枚举等于 `["refs","text","changes","full"]`；`chrome_act` 有 `see` 参数；`chrome_see` 有 `selector` 参数；`chrome_vision` 只有 `full_page`、`tab` 两个参数；`chrome_cdp` 只有 `method`、`params`、`tab` 三个参数。
- AC5：给 `chrome_act` 的 schema 加一个无描述的字段后，AC3 的断言仍应通过；再加 2,000 字符的字段描述后，AC3 转红。
- AC6：传 `{"tools":{"chrome_cdp":{"enabled":false}}}` 时注册 4 个工具，且汇总出的规则里不含 `chrome_cdp`。
- AC7：传 `{"tools":{"chrome_act":{"name":"chrome_click"}}}` 时注册的第一个工具名是 `chrome_click`。
- AC8：传 `{"guidance":{"chrome_see":{"description":"X"}}}` 时，`chrome_see` 的 description 等于 `"X"`。
- AC9：传 `{"guidance":{"chrome_act":{"promptGuidelines":["a","b"]}}}` 时，`chrome_act` 的规则只剩 `a` 与 `b`。
- AC10：默认配置下每个启用工具的每条默认规则都以工具名开头（例如 `chrome_act: `）。
- AC11：`before_agent_start` 触发后，`systemPromptOptions.promptGuidelines` 等于 `prompt.guidelines` 的默认数组。
- AC12：传 `{"prompt":{"guidelines":["x"]}}` 时，`systemPromptOptions.promptGuidelines` 只剩 `["x"]`，而工具自身的规则不受影响。
- AC13：5 个工具的 `description` 合计不超过 4,000 字符，全部参数描述合计不超过 5,500 字符。
