# T06 命令超时与错误分类

- [x] 已完成（2026-11-07 审计 pass）

## 交付物

在途命令表。超时后按三种失败原因给出不同消息。支持 `AbortSignal` 取消。

## 验收

- AC1：`pnpm --filter pi-browser-use-lite test bridge/timeout` 通过。
- AC2：扩展从未轮询时，超时消息含 `not polling`。
- AC3：扩展轮询过但没取走命令时，超时消息含 `did not pick up`。
- AC4：命令已投递但无结果时，超时消息含 `never returned a result`。
- AC5：`AbortSignal` 触发时 Promise 以含 `aborted` 的消息拒绝，且该命令不再出现在后续 `GET /next`。
- AC6：每条拒绝带的 `details.error` 含 `class` 与 `hint`，`class` 取值来自 [SPEC-0001](../specs/0001-tool-surface.md) 的错误表。
