# T09 轮询传输

- [ ] 未开始

## 交付物

`background/transport.js`：长轮询 `GET /next`，取到命令后调 dispatch，再用 `POST /result` 回传。

## 验收

- AC1：`pnpm --filter pi-browser-use-lite test -- extension/transport` 通过。
- AC2：`/next` 返回 `{"type":"none"}` 时，下一次请求在 100 毫秒后发生（轮询间隔由注入参数控制）。
- AC3：`/next` 返回命令时，调用 dispatch，并 `POST /result`，body 的 `id` 与命令一致。
- AC4：dispatch 抛错时，`POST /result` 的 `ok` 为 false 且 `error` 等于该错误消息。
- AC5：`chrome.alarms` 上注册了每 0.5 分钟一次的唤醒。
- AC6：握手时 `tab.version` 报回的版本与宿主不同时，该连接被标记为版本不匹配，后续工具调用给出 `extension_version` 错误且不发命令。
