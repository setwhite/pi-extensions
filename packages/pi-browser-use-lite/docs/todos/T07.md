# T07 多会话转发与抢占

- [ ] 未开始

## 交付物

`POST /command` 端点、client 模式转发、owner 不可达时抢占端口升为 server。

## 验收

- AC1：`pnpm --filter pi-browser-use-lite test -- bridge/multi-session` 通过。
- AC2：两个桥实例绑同一端口时，第二个的 `status().mode` 等于 `"client"`。
- AC3：两实例并存时，client 发命令后，命令出现在 server 的 `GET /next`，结果回到 client。
- AC4：关掉 server 后，client 的 `send()` 仍成功，且 `status().mode` 变成 `"server"`。
- AC5：带 `Origin: https://evil.example` 的 `GET /next` 返回 403。
- AC6：端口被非本包进程占用时启动即抛错，`class` 为 `bridge_unreachable`，消息含 `bridge.port` 与改端口的提示；不静默换端口。
- AC7：带 `Origin: https://evil.example` 的 `POST /result` 返回 403。
