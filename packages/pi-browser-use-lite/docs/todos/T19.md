# T19 授权与背景模式

- [ ] 未开始

## 交付物

`src/policy/` 的两个插点：授权开关、硬背景策略。本任务只出判定函数与会话状态。命令在 T21。

## 验收

- AC1：`pnpm --filter pi-browser-use-lite test -- policy` 通过。
- AC2：未授权时 5 个工具逐个调用都返回 `locked`，含只读的 `chrome_see` 与 `chrome_vision`；且桥没收到任何命令。
- AC3：授权打开后可调用；关闭后立即不可用，且关闭后桥没收到新命令。
- AC4：背景模式开启时 `chrome_tab` 的 `switch` 被拒，且没有任何参数能让单次调用绕过。
- AC5：会话结束回调触发后，授权状态回到未授权。断言代码里没有定时器。
- AC6：`policy.authorizeOnStart` 为 `true` 时，加载后不经任何命令即可调用工具。
