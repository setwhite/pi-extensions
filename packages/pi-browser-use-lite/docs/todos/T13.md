# T13 指针事件

- [ ] 未开始

## 交付物

`background/input/pointer.js`：移动、点击、悬停、拖动、滚轮。

## 验收

- AC1：`pnpm --filter pi-browser-use-lite test -- extension/input/pointer` 通过。
- AC2：点击一次依次发出 `mouseMoved`、`mousePressed`、`mouseReleased`。
- AC3：目标是元素时，坐标落在该元素矩形内。
- AC4：目标标签不可见时抛错，不回退到激活标签。
- AC5：`input.dragSteps` 为 3 时 `drag` 发出 3 次中间 `mouseMoved`；默认配置下为 10 次。
- AC6：`input.scrollSteps` 为 2 时 `scroll` 发出恰好 2 个 `mouseWheel` 事件；默认配置下为 5 个。
- AC7：`click` 的 `ref`、`selector`、`x`+`y` 三选一。一个都没给或给了多个时抛 `bad_args`，且未发出任何 CDP 事件。
