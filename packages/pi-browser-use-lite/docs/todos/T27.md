# T27 会话窗口

- [x] 已完成（2026-11-08 审计后修复）

## 交付物

每会话一个浏览器窗口：用 `chrome.windows.create`（`focused: false`）建，本会话的自动化 target 放在里面。分组整条链路删掉：`chrome_tab` 的 `group` 动作、`chrome.groupName` 与 `chrome.groupColor` 两个配置键、`manifest.json` 的 `tabGroups` 权限。

## 验收

- AC1：`pnpm lint`、`pnpm check:imports`、`pnpm typecheck`、`pnpm test` 退出 0。
- AC2：一个 sessionKey 一个窗口；同会话的新标签进同一个窗口；窗口被用户关掉后下一次 `tab.new` 重开。
- AC3：`tab.list` 只列本会话窗口里的标签。
- AC4：认 target 要「台账里有」且「在本会话窗口里」；不满足时只读动作报 `no_target`，陌生标签既不认也不关。
- AC5：浏览器启动时整份台账作废（`chrome.runtime.onStartup`），扩展重载不作废。
- AC6：`tab.activate` 激活标签后把窗口带到前台；后台模式下不碰 `chrome.tabs.update`，也不碰 `chrome.windows.update`。
- AC7：`chrome_tab` 只剩 `list`、`new`、`switch`、`close`；`chrome.groupName`、`chrome.groupColor` 与 `tabGroups` 权限消失。
- AC8：`pnpm test:e2e` 三条全过（导航、`click` 点 `#go` 得 PASS、截屏落盘），Vivaldi 与 Edge 各跑一次。
