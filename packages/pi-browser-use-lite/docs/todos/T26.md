# T26 等待与轮询

- [ ] 未开始

## 交付物

`browser-extension/background/page/waitFor.js`：`selector`、`expression`、`text` 三种 `kind`，轮询间隔 250 毫秒，默认 15 秒。轮询在 service worker 里用 CDP 求值，不在页面里跑循环——页面里的循环在严格 CSP 下起不来。

## 验收

- AC1：`pnpm --filter pi-browser-use-lite test extension/page/waitFor` 通过。
- AC2：`selector` 等 `document.querySelector(value)` 命中；`expression` 等表达式为真；`text` 等正文含 `value`。
- AC3：超时抛 `timeout: waiting for <kind> <value> timed out after <n>ms`。
- AC4：成功回 `{ waitedMs }`，宿主渲染成 `waited <n>ms`。
- AC5：间隔写死 250 毫秒，代码里读不到配置（SPEC-0001 非功能段）。
- AC6：`page.waitFor` 接进 `dispatch.js` 的路由表，该动作的 `… is not wired yet` 消失。
- AC7：页面求值本身报错时抛 `page_error:`，不当成「还没命中」静默重试。
