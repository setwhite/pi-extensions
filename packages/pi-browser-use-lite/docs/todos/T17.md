## 交付物

`background/page/snapshot.js` 与 `page/snapshot.js`（自包含）。4 个模式的输出字段按 spec。

## 验收

- AC1：`pnpm --filter pi-browser-use-lite test -- extension/page/snapshot` 通过。
- AC2：`refs` 模式的输出不含正文，含 500 字摘要与最多 80 个元素。
- AC3：`text` 模式把标题树排在正文之前，正文不超过 `output.textChars`。`full` 不超过 30,000 字符。`changes` 只给 diff。
- AC4：同一元素连续两次快照得到同一 ref；ref 单调递增不复用。
- AC5：`query` 的 token 完全命中时，该元素排第一。
- AC6：注入后拿不到 `window.__piChromeSnapshotPage` 时，抛出的消息含该名字。
- AC7：`changes` 只报元素三元组（标签、角色、可见文本）的增、删、改，不报位置移动，条目不超过 20 条。
- AC8：`changes` 的基线按标签页保存，跨 `mode` 切换保留。该标签页第一次快照时 `changes` 为空，并注明没有上一次快照。
- AC9：同时传 `ref` 与 `selector` 时以 `ref` 为准，不报错。
- AC10：`changes` 的输出不超过 600 字符，超出时从上到下丢弃条目并在末行注明丢弃条数。
- AC11：静态扫描 `browser-extension/page/*.js`，断言不含 `import`、`export`、`require`、动态 `import()`。
