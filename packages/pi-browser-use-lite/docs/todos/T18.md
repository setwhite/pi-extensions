# T18 截屏与保留期

- [ ] 未开始

## 交付物

`background/page/screenshot.js`、`src/fs/` 的落盘与修剪。

## 验收

- AC1：`pnpm --filter pi-browser-use-lite test extension/page/screenshot` 通过。
- AC2：不传 `full_page` 时只产出一个文件，尺寸等于视口。
- AC3：`full_page` 且整页高度不超过 4 倍视口时，产出一个整页文件。超过时产出 N 个按屏分段的文件，文件名含 `-1ofN` 到 `-NofN`。
- AC4：不产出 `.json` 文件，不做图像拼接。
- AC5：修剪只保留最新 `screenshot.keepNewest` 个文件。代码里没有按天数的修剪逻辑。
- AC6：返回的 `details.path` 指向的文件真实存在。
- AC7：`screenshot.format` 为 `"jpeg"` 时落盘文件名以 `.jpeg` 结尾。
- AC8：一次分块截图产生的 N 个文件各占 `screenshot.keepNewest` 的一个保留位。
- AC9：`screenshot.dir` 默认 `~/.pi/screenshots`，`~` 展开为家目录；目录不存在时自动创建。
- AC10：整页截图超时按 120 秒算，超过后返回 `timeout`。
