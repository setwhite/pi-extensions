# T11 标签页管理

- [x] 已完成（2026-11-07 审计 pass）

## 交付物

`background/tabs.js`：list、new、activate、close、group、navigate（含 `init_script`），以及会话标签台账。

## 验收

- AC1：`pnpm --filter pi-browser-use-lite test -- extension/tabs` 通过。
- AC2：`tab.new` 建的标签加入本会话组；分组失败时该标签被关闭，且抛错。
- AC3：`tab.list` 只返回本会话创建或已加入本会话组的标签。
- AC4：后台模式下 `tab.activate` 抛错，且未调用 `chrome.tabs.update`。
- AC5：创建到跟踪之间有等待：早期捕获在 `pendingTabCreations` 上等，不报 `tab not found`。
- AC6：用户把某标签手动拖出本会话组后，`tab.list` 不再返回它。
- AC7：`chrome_act navigate` 带 `init_script` 时，脚本在本次导航的文档开始前注入（`Page.addScriptToEvaluateOnNewDocument`），导航完成后移除，不影响后续导航。
- AC8：`tab.new` 建组时把 `chrome.groupName` 与 `chrome.groupColor` 交给 `chrome.tabGroups.update`。
- AC9：`navigate` 的等待上限取 `timing.navigateTimeoutMs`；注入 100 毫秒时，未加载完的页面在超时后报 `timeout`。
