# T05 桥服务与端点

- [x] 已完成（2026-11-07 审计 pass）

## 交付物

`src/protocol/` 放命令与结果信封类型、动作名表、超时常量。`src/bridge/` 起 `node:http` 服务，实现 `GET /next`、`POST /result`、`GET /status`。挂起时长与端口由构造函数注入，便于测试。

## 验收

- AC1：`pnpm --filter pi-browser-use-lite test -- bridge/server` 通过。
- AC2：无命令时，以 50 毫秒挂起时长调 `GET /next`，50 毫秒后返回 `{"type":"none"}`。
- AC3：先发一个命令再调 `GET /next`，立刻返回 `{"type":"command","command":{"id":"…","action":"…"}}`。
- AC4：`POST /result` 带未知 id 返回 404；带已知 id 时，对应命令的 Promise 以该结果 resolve。
- AC5：`GET /status` 返回的对象里 `mode` 等于 `"server"`。
- AC6：连续发两个命令后，两次 `GET /next` 按到达顺序各返回一条，不合并、不并发。
- AC7：扩展从未轮询时 `GET /status` 的 `connected` 为 `false`；轮询过一次之后为 `true`。
- AC8：不注入挂起时长时，`GET /next` 的默认挂起为 25 秒。
