# T03 配置契约

- [x] 已完成（2026-11-06 审计 pass）

## 交付物

`src/config/` 按 [SPEC-0001](../specs/0001-tool-surface.md) 的配置契约实现 `loadConfig(dir)`。同模块导出 `configPath()`：`PI_CODING_AGENT_DIR` 存在时取该目录，否则取 `~/.pi/agent`，再加 `pi-browser-use-lite/config.json`。15 个标量字段分 8 组：`bridge`、`chrome`、`policy`、`input`、`timing`、`output`、`screenshot`、`prompt`；另有 `tools`（5 个工具 × 2 项）与 `guidance`（5 个工具 × 3 项）两个记录。

文件切分照 `pi-web-search-lite`：`schema.ts` 只放公开常量、类型与默认值；校验逻辑在 `validate.ts`。config 模块只依赖 `node:` 标准库。

## 验收

- AC1：`pnpm --filter pi-browser-use-lite test config` 通过。
- AC2：传空目录时，返回值的 15 个标量逐个等于 `schema.ts` 里的默认值，且 `bridge.port` 等于 17318、5 个工具的 `enabled` 全为 `true`、`name` 等于各自原名。
- AC3：传含 `{oops` 的 config.json 时，抛 `Error`，且消息含该文件的路径。
- AC4：传 `{"bridge":{"port":99999}}` 时，返回值的 `bridge.port` 等于 65535，不抛错。
- AC5：传 `{"chrome":{"groupColor":"rainbow"}}` 时，返回值的 `chrome.groupColor` 等于 `"blue"`，不抛错。
- AC6：5 个工具全 `enabled: false` 时抛 `Error`，且消息含 `tools`。
- AC7：传 `{"tools":{"chrome_act":{"name":"Bash"}}}` 时抛 `Error`，且消息含 `tools.chrome_act.name`。
- AC8：传 `{"tools":{"chrome_act":{"name":"read"}}}` 时抛 `Error`，且消息含 `reserved`。
- AC9：传 `{"tools":{"chrome_act":{"name":"chrome_see"}}}` 时抛 `Error`，且消息含 `same name`。
- AC10：传 `{"guidance":{"chrome_act":{"desc":"x"}}}` 时抛 `Error`，且消息含 `guidance.chrome_act.desc`。
- AC11：传 `{"guidance":{"chrome_act":{"promptGuidelines":[]}}}` 时，返回值的 `guidance.chrome_act.promptGuidelines` 等于空数组，其余工具仍为内置规则。
- AC12：传 `{"prompt":{"guidelines":[]}}` 时，返回值的 `prompt.guidelines` 等于空数组，不抛错。
- AC13：传 `{"prompt":{"guideline":["a"]}}` 时抛 `Error`，且消息含 `prompt.guideline`。
- AC14：传 `{"screenshot":{"retentionDays":7}}` 时抛 `Error`，且消息含 `screenshot.retentionDays`。
- AC15：设 `PI_CODING_AGENT_DIR` 时 `configPath()` 以该目录开头并以 `pi-browser-use-lite/config.json` 结尾；未设时以 `~/.pi/agent` 开头。
