# T21 /chrome 命令

- [x] 已完成（2026-11-08 审计后修复）

## 交付物

`src/commands/`：`authorize on|off`、`status`、`background on|off`。三个子命令。

## 验收

- AC1：`pnpm --filter pi-browser-use-lite test commands` 通过。
- AC2：`/chrome` 不带参数时列出 3 个子命令，且不含 `doctor` 与 `onboard`。
- AC3：桥未连接时 `/chrome authorize on` 打印装扩展的步骤，且不授权；`/chrome status` 打印同样的步骤。
- AC4：桥未连接时不发任何浏览器命令。
- AC5：`/chrome status` 的输出含 [SPEC-0001](../specs/0001-tool-surface.md) 列的 8 项：版本、授权、背景模式、桥角色、端口、连接状态、在途命令数、本会话 target。
- AC6：`/chrome background on` 与 `off` 改写会话状态后，`/chrome status` 反映该状态。
